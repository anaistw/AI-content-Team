# AI-content-Team
Goal: Build a personal brand. Build a portfolio to apply for jobs and get a job in marketing

Therefore, I built an AI Content Team. 

Meet the Team:
- Scout Sami: Every day (+ trends on Mondays)
Turns my Instagram saves and trending formats into short idea pages

- Planner Pia:	Friday	
Plans the next two weeks of filming, around my calendar and what's working

- Producer Rosa:	Saturday	
Turns the posts I approve into one-screen briefs and a shoot list

- Analyst Ana: Sunday	
Updates the numbers and writes a 6-line weekly check

- Case-study Cleo:	1st of the month	
Turns last month into a one-page case study for job applications

- Builder Bea:	Wednesday	
Suggests small tools and automations I can build for my portfolio

& Me: Always	I approve, film and post.

# A normal week

Every morning, Sami adds up to 3 new ideas from posts I saved.
Friday, Pia plans what to film, using Ana's latest check and my calendar.
Friday night, I tick "Approved" on the posts I like on my notion.
Saturday, Rosa sends me a shoot list, and I film in one session.
Sunday, Ana tells me what worked, what didn't and what's next.

The loop closes itself: Ana's insights shape Pia's next plan.

# The rules that make it work

One job each. Every agent has a clear role, and it knows what it owns and what it must never touch.
I stay in control. Agents suggest and prepare. Only I approve, film and post.

Short beats complete. I got overwhelmed by long pages, so every brief fits on one phone screen and every check is 6 lines.

One brand guide for everyone. All agents read the same brand page first, so the voice stays mine.
Honest numbers. Agents only use real data and say so when there isn't enough.

# What I learned
Designing the team was a marketing job. Roles, handoffs and feedback loops are the same skills you need to run a real content team.
Less is more. My first version produced too many ideas. Limiting each agent made the whole system better.
The feedback loop is the magic. Content gets better because the numbers flow back into the plan.
How it's built

Claude runs each agent as a scheduled task with its own prompt.
Notion is the shared workspace: an ideas database, a post tracker and weekly reviews.

No code written by hand. Everything was set up by prompting.
The prompts for each agent are in agents/.
